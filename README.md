This is my first time using github and it took me an embarrasing amount of time just to create an account and even more time to make a repository. I'm not sure exactly what you're supposed to add in the repository or what you're supposed to write here so I just hope I'm doing this correctly.

## Controls
- Move left: A / left arrow key
- Move right: D / right arrow key
- Jump: Space, w, up arrow key
